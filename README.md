# 📊 Modelagem de Banco de Dados – Oficina Mecânica

Este repositório contém a **modelagem de banco de dados (DER – Diagrama Entidade-Relacionamento)** para um sistema de **Oficina Mecânica**, desenvolvido com foco em estudo, organização de requisitos e boas práticas de modelagem.

---

## 🎯 Objetivo do Projeto

Modelar a estrutura de dados necessária para gerenciar:

- Clientes
- Ordens de Serviço
- Veículos
- Serviços realizados
- Controle básico de informações da oficina

O objetivo principal é **representar corretamente as entidades, atributos e relacionamentos**, servindo como base para implementação futura em um banco de dados relacional.

---

## 🗂 Estrutura do Repositório

├── Oficina_mecanica/
  ├── Oficina_mecanica.mwb # Modelo no MySQL Workbench
  ├── Oficina_mecanica.mwb.bak # Backup automático do Workbench
  └── Oficina_mecanica.pdf # DER exportado em PDF
├── README.md


---

## 🛠 Ferramentas Utilizadas

- **MySQL Workbench**
  - Criação do DER
  - Exportação do diagrama em PDF
- **Git / GitHub**
  - Versionamento do projeto

---

## 📄 Descrição dos Arquivos

- **`.mwb`**  
  Arquivo principal do modelo de dados, editável no MySQL Workbench.

- **`.mwb.bak`**  
  Backup automático gerado pela ferramenta.

- **`.pdf`**  
  Versão visual do Diagrama Entidade-Relacionamento para consulta rápida.
