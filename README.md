# 📊 Modelagem de Banco de Dados – Oficina Mecânica

Este repositório contém a **modelagem de banco de dados** (DER – Diagrama Entidade‑Relacionamento) de um sistema de **Oficina Mecânica**, desenvolvido com foco em **estudo**, **organização de requisitos** e **boas práticas de modelagem relacional**.

O projeto serve como base conceitual para futura implementação em um banco de dados e integração com aplicações backend.

---

## 🎯 Objetivo do Projeto

Modelar a estrutura de dados necessária para gerenciar os principais processos de uma oficina mecânica, incluindo:

* Cadastro de clientes
* Gerenciamento de veículos
* Ordens de serviço
* Serviços realizados
* Controle básico das informações operacionais da oficina

O objetivo principal é representar corretamente **entidades**, **atributos** e **relacionamentos**, garantindo clareza, consistência e possibilidade de evolução.

## 🛠 Tecnologias e Ferramentas Utilizadas

* **MySQL Workbench**

  * Criação e edição do Diagrama Entidade‑Relacionamento (DER)

* **Git / GitHub**

  * Versionamento do projeto
  * Organização e histórico de alterações

---

## 📄 Descrição dos Arquivos

### 🔹 Oficina_mecanica.mwb

Arquivo principal do modelo de dados. Deve ser aberto e editado no **MySQL Workbench**.

### 🔹 Oficina_mecanica.mwb.bak

Arquivo de **backup automático**, gerado pelo MySQL Workbench para prevenção de perda de dados.

### 🔹 Oficina_mecanica.pdf

Versão visual do Diagrama Entidade‑Relacionamento, indicada para consulta rápida e compartilhamento.
